## ☁️ About the Project

**A Little Universe for Dunk Natachai** is a fan-made website created to celebrate Dunk through a soft, minimal, and dreamy design.

Featuring warm cream tones, peach accents, and a cozy aesthetic, this little website is a creative coding project made with love for a favorite actor.

Sometimes, a little corner of the internet is all you need to appreciate someone who makes you smile. 🤎

## ✨ Features

- 🤎 Soft cream, peach, and brown color palette
- 🌙 Minimal and dreamy user interface
- 📱 Responsive layout for mobile and desktop
- 🎬 A section dedicated to Dunk's dramas
- 📸 Photo gallery
- 💌 Interactive wish buttons
- ✨ Smooth animations and visual details

## 🛠️ Built With

- **HTML5** — Website structure
- **CSS3** — Styling, layout, animations, and responsiveness
- **JavaScript** — Interactive elements and button functionality

## 🚀 Run Locally

1. Clone or download this repository.
2. Keep `index.html` and the required image files in the same folder.
3. Open `index.html` in your browser.
4. Explore the website!

## 🌐 Deployment

This website can be hosted for free using **GitHub Pages**.

Once GitHub Pages is enabled in the repository settings, the website can be accessed through its published URL.
